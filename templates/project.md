# PROJECT TEMPLATE

## Objetivo

Esta plantilla define la estructura estándar para publicaciones que muestran un proyecto u obra realizada por Aberturas VC.

Debe utilizarse cuando el objetivo principal sea demostrar calidad, experiencia y confianza mediante proyectos reales.

---

# Cuándo utilizar

Utilizar esta plantilla cuando:

- Se muestra una obra terminada.
- Se presenta un proyecto destacado.
- Se exhibe una instalación finalizada.
- Se quiere reforzar la confianza mediante trabajos reales.

No utilizar para:

- Beneficios generales.
- Publicaciones institucionales.
- Promociones.
- Información técnica.

---

---

# Fotografía

Priorizar siempre fotografías reales.

La fotografía debe mostrar el proyecto completo.

Las aberturas deben integrarse con la arquitectura.

Evitar fotografías demasiado cerradas cuando no aporten contexto.

---

# Copy

El título debe comunicar un beneficio.

Ejemplos:

- Aberturas que transforman espacios.
- Calidad para tu proyecto.
- Diseño y confort.
- Grandes superficies vidriadas.

---

# CTA

Opcional.

Ejemplos:

- Solicitá tu presupuesto.
- Consultanos.
- Conocé nuestros proyectos.

Debe ser breve y natural.

---

# Composición

La fotografía ocupa la mayor parte del diseño.

El texto nunca debe competir con la imagen.

Mantener mucho espacio en blanco.

Existe un único punto focal.

---

# Identidad

La publicación debe transmitir:

- Calidad.
- Profesionalismo.
- Confianza.
- Arquitectura moderna.
- Experiencia.

---

# Reglas IA

Antes de generar la pieza verificar:

□ La fotografía es real.

□ El proyecto es protagonista.

□ Existe un único mensaje.

□ El logo funciona como firma.

□ La composición respeta el Design System.
