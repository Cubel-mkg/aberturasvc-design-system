# AUDIENCE

## Objetivo

Definir los públicos principales de Aberturas VC y orientar la comunicación según el beneficio que se desea transmitir.

La elección del público debe realizarse antes de definir el mensaje de cualquier pieza.

---

# Públicos

## Familias

Buscan:

- Confort
- Seguridad
- Aislamiento térmico
- Aislamiento acústico
- Ahorro energético
- Calidad de vida

Mensajes recomendados:

- Viví más cómodo.
- Disfrutá un hogar silencioso.
- Reducí el consumo energético.
- Más confort durante todo el año.

---

## Arquitectos

Buscan:

- Diseño
- Estética
- Grandes superficies vidriadas
- Minimalismo
- Calidad constructiva

Mensajes recomendados:

- Diseño contemporáneo.
- Integración entre interior y exterior.
- Arquitectura moderna.

---

## Constructoras

Buscan:

- Cumplimiento
- Calidad
- Producción
- Rapidez
- Servicio

Mensajes recomendados:

- Cumplimiento de obra.
- Producción confiable.
- Soluciones para proyectos.

---

## Desarrolladores

Buscan:

- Escalabilidad
- Producción
- Calidad constante
- Experiencia

Mensajes recomendados:

- Soluciones para grandes desarrollos.
- Capacidad de producción.
- Calidad certificada.

---

# Relación entre beneficio y público

| Beneficio | Público principal |
|-----------|-------------------|
| Aislamiento térmico | Familias |
| Aislamiento acústico | Familias |
| Seguridad | Familias |
| Diseño | Arquitectos |
| Arquitectura moderna | Arquitectos |
| Producción | Constructoras |
| Cumplimiento | Constructoras |
| Escalabilidad | Desarrolladores |
| Calidad constante | Desarrolladores |

---

# Regla

Antes de comenzar cualquier diseño:

1. Definir el beneficio.
2. Identificar el público asociado.
3. Adaptar el tono y el mensaje según ese público.

Nunca intentar comunicar para todos los públicos al mismo tiempo.
