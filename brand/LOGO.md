# LOGO

# Objetivo

Definir las reglas oficiales para el uso del logotipo de Aberturas VC.

El logotipo representa la identidad visual de la empresa y debe utilizarse de forma consistente en todos los medios.

Nunca modificar el logotipo sin autorización.

---

# Función

El logotipo identifica la marca.

Debe funcionar como una firma.

No debe competir con el contenido principal.

---

# Versiones permitidas

Se permiten únicamente las versiones oficiales.

- Logo principal.
- Logo blanco.
- Logo negro.
- Logo para fondos oscuros (si corresponde).

No crear versiones nuevas.

---

# Ubicación

Ubicaciones recomendadas:

- Esquina inferior derecha.
- Esquina inferior izquierda.
- Encabezados institucionales.
- Pie de página.

Mantener siempre una posición consistente.

---

# Área de seguridad

Debe existir un espacio libre alrededor del logotipo.

Ningún texto, fotografía o elemento gráfico puede invadir esa zona.

El área de seguridad garantiza una correcta lectura.

---

# Tamaño

El logotipo debe ser claramente visible.

Nunca utilizar tamaños tan pequeños que dificulten su lectura.

Tampoco debe ocupar un espacio excesivo dentro de la composición.

---

# Contraste

El logotipo siempre debe mantener un contraste adecuado con el fondo.

Si el fondo dificulta la lectura:

- Utilizar la versión blanca.
- Utilizar la versión negra.
- Incorporar un fondo sólido o un overlay.

Nunca sacrificar legibilidad.

---

# Sobre fotografías

El logotipo puede colocarse sobre fotografías únicamente cuando exista suficiente contraste.

Priorizar zonas con poco ruido visual.

Evitar colocarlo sobre detalles complejos.

---

# Qué evitar

No:

- Estirar el logotipo.
- Comprimir el logotipo.
- Cambiar colores.
- Rotarlo.
- Agregar efectos.
- Aplicar sombras.
- Cambiar proporciones.
- Agregar contornos.

Utilizar siempre los archivos oficiales.

---

# Reglas IA

Antes de generar una pieza verificar:

□ El logotipo es claramente legible.

□ Se utiliza una versión oficial.

□ Respeta el área de seguridad.

□ Funciona como firma.

□ No compite con el mensaje principal.
