# COLORS

## Objetivo

Definir la paleta oficial de Aberturas VC y las reglas para utilizar cada color.

La consistencia del color es uno de los elementos más importantes de la identidad visual.

Nunca incorporar colores nuevos sin una razón justificada.

---

# Color Primario

Nombre:
Azul Corporativo

HEX:
#074584

Uso:

- Fondo institucional
- Botones principales
- Etiquetas
- Banners
- Destacar información importante
- Elementos de identidad

Representa:

- Profesionalismo
- Confianza
- Tecnología
- Calidad
- Seguridad

---

# Blanco

HEX

#FFFFFF

Uso

- Texto sobre fondo azul
- Fondos limpios
- Espacios negativos
- Respiración visual

Representa

- Claridad
- Limpieza
- Modernidad

---

# Negro

HEX

#111111

Uso

- Texto
- Contraste
- Fotografías

Nunca utilizar como color dominante.

---

# Gris Claro

HEX

#F5F5F5

Uso

Fondos secundarios.

Separación de bloques.

Nunca utilizar para elementos importantes.

---

# Uso del color

El azul siempre debe ser el color dominante de la identidad.

El blanco debe aportar aire.

El negro debe utilizarse únicamente para generar contraste.

Nunca competir con la fotografía.

---

# Proporción recomendada

Azul

60%

Fotografía

25%

Blanco

10%

Otros

5%

---

# Reglas

Siempre utilizar alto contraste.

Nunca utilizar texto azul sobre fotografías oscuras.

Nunca utilizar texto blanco sobre fotografías claras.

Si la fotografía dificulta la lectura, utilizar un overlay azul institucional con opacidad.

---

# Qué evitar

No utilizar:

- degradados
- colores fluorescentes
- colores saturados
- sombras de color
- combinaciones estridentes

---

# Principio

El color debe reforzar la identidad.

Nunca debe convertirse en el protagonista del diseño.

El protagonista siempre será el mensaje y la fotografía.
