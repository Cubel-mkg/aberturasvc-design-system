# CAMPAIGN_STRATEGY

# Objetivo

Definir la estrategia de comunicación antes de comenzar cualquier pieza gráfica.

Toda campaña debe responder primero una pregunta:

**¿Qué queremos comunicar y para quién?**

La estrategia siempre debe definirse antes del diseño.

---

# Principios

Una campaña no comienza con un diseño.

Comienza con un objetivo.

La IA nunca debe comenzar seleccionando colores, componentes o fotografías.

Primero debe comprender el objetivo comercial.

---

# Flujo estratégico

Toda campaña debe responder, en este orden:

1. Objetivo.
2. Público principal.
3. Beneficio principal.
4. Mensaje.
5. Patrón.
6. Fotografía.
7. Componentes.
8. Copy.
9. CTA.
10. Control de calidad.

Nunca alterar este orden.

# Selección del beneficio

Elegir únicamente un beneficio principal.

Nunca intentar comunicar varios beneficios importantes en la misma pieza.

Si existen múltiples beneficios posibles, seleccionar el que mejor responda al objetivo de la campaña.

---

# Selección del mensaje

Todo mensaje debe responder:

¿Qué obtiene el cliente?

Nunca comenzar hablando de perfiles, materiales o especificaciones técnicas.

Primero comunicar el beneficio.

Luego, si es necesario, explicar cómo se consigue.

---

# Selección de fotografía

Consultar PHOTOGRAPHY.md.

La fotografía debe reforzar el beneficio principal.

Nunca seleccionar una imagen únicamente porque sea atractiva.

Debe apoyar la estrategia de comunicación.

---

# Selección del patrón

Consultar DECISION_TREE.md.

El patrón debe elegirse según el objetivo.

Nunca por preferencia estética.

---

# Reglas para IA

Antes de comenzar cualquier diseño responder internamente:

¿Cuál es el objetivo?

¿Quién es el público principal?

¿Qué beneficio quiero comunicar?

¿Qué debe sentir el cliente después de ver la pieza?

Si alguna de estas respuestas no está clara, detener el proceso e indicarlo.

---

# Resultado esperado

Cada campaña debe comunicar una sola idea.

Debe ser comprendida en menos de tres segundos.

Debe parecer creada exclusivamente para Aberturas VC.

Debe mantener coherencia con todas las publicaciones anteriores.

La consistencia siempre tiene prioridad sobre la creatividad.
