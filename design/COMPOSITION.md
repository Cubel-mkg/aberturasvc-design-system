# COMPOSITION

---

# Objetivo

Definir cómo se organizan los elementos dentro de una composición para mantener una identidad visual consistente.

Una buena composición permite que el usuario comprenda el mensaje rápidamente.

---

# Principio principal

Cada diseño debe tener un único punto focal.

Si existen dos elementos compitiendo por la atención, la composición debe simplificarse.

---

# Orden de lectura

Toda pieza debe respetar este flujo visual:

1. Fotografía.

↓

2. Título.

↓

3. Beneficio.

↓

4. CTA.

↓

5. Logo.

Nunca alterar este orden sin una razón justificada.

---

# Peso visual

Distribución recomendada:

Fotografía

70%

Tipografía

20%

Logo

5%

Elementos gráficos

5%

La fotografía siempre debe dominar la composición.

---

# Espacios en blanco

Los espacios vacíos forman parte del diseño.

Nunca intentar llenar todos los espacios disponibles.

Más aire transmite mayor calidad.

---

# Alineación

Priorizar:

- Izquierda.

Puede utilizarse:

- Centrado.

Evitar alineaciones inconsistentes dentro de una misma pieza.

---

# Contraste

El texto siempre debe mantener una lectura inmediata.

Si la fotografía dificulta la lectura:

- utilizar overlay.
- cambiar el color del texto.
- mover el bloque de contenido.

Nunca sacrificar legibilidad.

---

# Jerarquía

Siempre debe existir una diferencia clara entre:

Título.

↓

Beneficio.

↓

CTA.

↓

Logo.

Nunca utilizar tamaños similares para todos los textos.

---

# Balance

La composición debe sentirse equilibrada.

Si un lado tiene demasiado peso visual, redistribuir los elementos.

---

# Movimiento visual

Guiar la mirada del usuario.

Evitar composiciones caóticas.

Cada elemento debe conducir naturalmente al siguiente.

---

# Reglas IA

Antes de aprobar una composición verificar:

□ Existe un punto focal claro.

□ La fotografía domina.

□ El título es fácil de encontrar.

□ El CTA aparece al final.

□ El logo funciona como firma.

□ Hay suficiente espacio libre.

□ El diseño transmite orden.

---

# Resultado esperado

El usuario debe comprender la publicación en menos de tres segundos.

Si necesita detenerse para entenderla, la composición debe simplificarse.
