# LAYOUT_RULES

# Objetivo

Definir la estructura visual de todas las piezas gráficas de Aberturas VC.

El layout organiza la información.

Debe permitir que cualquier publicación sea reconocible como parte de la marca incluso antes de leer el contenido.

---

# Principios

La fotografía siempre es el elemento protagonista.

El diseño debe acompañar a la fotografía, nunca competir con ella.

Cada pieza debe tener un único punto focal.

La lectura debe realizarse de forma natural y rápida.

El usuario debe comprender el mensaje principal en menos de tres segundos.

---

# Distribución visual

## Fotografía

Ocupar aproximadamente entre el 70% y el 80% del impacto visual.

Siempre utilizar imágenes limpias, luminosas y con espacio suficiente para integrar texto cuando corresponda.

Nunca utilizar fotografías con exceso de elementos que dificulten la lectura.

---

## Título

Debe ser el elemento tipográfico de mayor jerarquía.

Máximo:

- 2 líneas recomendadas.
- 3 líneas como límite absoluto.

Debe comunicar el beneficio principal.

Nunca describir únicamente el producto.

---

## Texto de apoyo

Debe ampliar la idea del título.

Máximo:

- 2 o 3 líneas.

Nunca repetir el título.

---

## CTA

Siempre visible.

Nunca competir con el título.

Debe funcionar como una invitación.

No como una presión comercial.

---

## Logo

Funciona como firma.

Nunca como protagonista.

Ubicación preferida:

Esquina inferior derecha.

Mantener siempre el área de seguridad definida en LOGO_PLACEMENT.md.

---

# Espacio negativo

El espacio vacío comunica calidad.

Nunca llenar todos los espacios disponibles.

Cuando exista una duda:

Elegir siempre más aire.

---

# Jerarquía

Orden obligatorio:

Fotografía

↓

Título

↓

Beneficio

↓

CTA

↓

Logo

Nunca alterar este orden.

---

# Alineación

Priorizar alineación izquierda.

Evitar centrar grandes bloques de texto.

Mantener consistencia entre publicaciones.

---

# Balance visual

Distribuir correctamente el peso de la composición.

Evitar concentrar todos los elementos en un único sector.

La pieza debe sentirse equilibrada.

---

# Reglas para IA

Antes de comenzar el diseño responder:

¿Dónde estará el punto focal?

¿Dónde descansará la vista después del punto focal?

¿Existe suficiente espacio para respirar?

¿El recorrido visual es claro?

Si alguna respuesta es NO, reorganizar el layout antes de continuar.
