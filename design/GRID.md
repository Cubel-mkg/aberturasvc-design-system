# GRID.md
# GRID

---

# Objetivo

Definir una estructura visual consistente para todas las piezas gráficas de Aberturas VC.

El grid no debe limitar la creatividad.

Debe aportar orden.

---

# Principio

Toda composición debe construirse sobre una estructura.

Nunca ubicar elementos de forma aleatoria.

---

# Márgenes

Mantener siempre márgenes amplios.

Los elementos nunca deben quedar pegados al borde.

El aire forma parte del diseño.

---

# Columnas

Para publicaciones de Instagram utilizar una estructura flexible.

No es obligatorio dividir la pieza en columnas visibles.

La prioridad es mantener equilibrio visual.

---

# Alineación

Todos los elementos importantes deben compartir una alineación común.

Evitar mover cada bloque de forma independiente.

---

# Espaciado

Los espacios entre elementos deben ser consistentes.

No generar separaciones aleatorias.

---

# Fotografía

La fotografía puede romper el grid si mejora la composición.

Los textos no.

---

# Logo

Debe respetar siempre el margen de seguridad.

Nunca colocarlo al borde de la composición.

---

# Adaptabilidad

El grid debe funcionar para:

- Instagram Feed
- Carruseles
- Stories
- Reels
- Presentaciones
- Landing Pages

---

# Reglas IA

Antes de finalizar una composición verificar:

□ Existe una alineación clara.

□ Los márgenes son consistentes.

□ Ningún elemento quedó pegado al borde.

□ El espacio negativo ayuda a la lectura.

□ La composición transmite orden.

---

# Resultado esperado

El usuario no debe percibir el grid.

Debe percibir una composición limpia, equilibrada y profesional.
