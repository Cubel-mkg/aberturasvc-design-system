# Icons

## Objetivo

Esta carpeta contiene todos los íconos oficiales utilizados por Aberturas VC.

Los íconos deben reforzar la identidad visual de la marca y mantener un lenguaje gráfico consistente en todas las piezas.

---

## Contenido esperado

Esta carpeta puede incluir:

- Íconos SVG
- Versiones PNG
- Librerías de íconos
- Variantes monocromáticas
- Versiones optimizadas para web

---

## Reglas

- Mantener un único estilo visual.
- Priorizar íconos simples y modernos.
- Utilizar siempre el mismo grosor de línea dentro de una colección.
- Evitar mezclar estilos diferentes (outline, filled, 3D, etc.).
- No utilizar íconos decorativos sin función.

---

## Formatos recomendados

- .svg
- .png
- .pdf

---

## Objetivo final

Construir una biblioteca de íconos consistente que facilite el diseño y mantenga la identidad visual de Aberturas VC en todos los canales.
