# Examples

## Objetivo

Esta carpeta contiene ejemplos visuales oficiales de Aberturas VC.

Los ejemplos sirven como referencia visual para mantener consistencia en futuras piezas.

No deben copiarse literalmente.

Deben utilizarse para comprender:

- Composición.
- Jerarquía visual.
- Uso de fotografía.
- Tratamiento del logo.
- Uso de tipografía.
- Uso de color.
- Espaciado.
- Estilo general de comunicación.

---

## Prioridad

Los ejemplos reales de Aberturas VC tienen prioridad sobre referencias genéricas.

Cuando exista un ejemplo que represente correctamente una determinada pieza, utilizarlo como referencia antes que inventar una nueva solución visual.

---

## Organización

### instagram/

Ejemplos de publicaciones individuales de Instagram.

### stories/

Ejemplos de historias de Instagram.

### carousels/

Ejemplos de carruseles.

---

## Regla

Los ejemplos funcionan como referencia del lenguaje visual de Aberturas VC.

No deben considerarse plantillas rígidas.

La información de estrategia, identidad y sistema visual documentada en `design/` tiene prioridad cuando exista una diferencia.
