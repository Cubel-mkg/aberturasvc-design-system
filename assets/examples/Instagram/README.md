# Instagram Examples

## Objetivo

Esta carpeta contiene ejemplos visuales utilizados como referencia para el diseño de publicaciones de Instagram de Aberturas VC.

---

## Uso

Los ejemplos sirven para analizar:

- Composición.
- Jerarquía visual.
- Uso de fotografía.
- Tipografía.
- Color.
- Espaciado.
- Tratamiento del logo.
- Relación entre imagen y texto.
- Estilo general de comunicación.

---

## Regla

Los ejemplos son referencias visuales.

No deben copiarse literalmente.

No deben reemplazar las reglas documentadas en el Design System.

Cuando exista una diferencia entre un ejemplo y una regla del sistema, la documentación del Design System tiene prioridad.

---

## Diferencia respecto de Photos

Los archivos de esta carpeta son referencias de diseño.

Las fotografías que deben utilizarse como contenido deben buscarse dentro de:

`assets/photos/`
