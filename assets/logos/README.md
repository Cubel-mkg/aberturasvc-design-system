# Logos

## Objetivo

Esta carpeta almacena todas las versiones oficiales del logotipo de Aberturas VC.

Los archivos aquí contenidos representan la única fuente válida para utilizar la identidad visual de la empresa.

---

## Contenido esperado

Esta carpeta puede incluir:

- Logo principal
- Logo horizontal
- Logo vertical
- Isotipo
- Versiones positivas
- Versiones negativas
- Versiones monocromáticas
- Favicons
- Manuales de uso del logo

---

## Formatos recomendados

Priorizar siempre formatos vectoriales.

- .svg
- .pdf
- .ai
- .eps

Para uso digital también pueden incluirse:

- .png (fondo transparente)
- .webp

Evitar utilizar archivos JPG como versión maestra.

---

## Reglas

- Nunca modificar las proporciones del logo.
- Nunca cambiar los colores institucionales.
- Nunca agregar efectos, sombras o degradados.
- Nunca utilizar versiones antiguas del logotipo.
- Utilizar únicamente archivos aprobados por la marca.

---

## Relación con el Design System

Las reglas de uso del logo se encuentran documentadas en:

- brand/LOGO.md
- components/LOGO_PLACEMENT.md

Esta carpeta contiene únicamente los archivos gráficos oficiales.

---

## Objetivo final

Garantizar que toda aplicación del logotipo sea consistente en todos los medios digitales e impresos.
