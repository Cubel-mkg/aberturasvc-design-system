# Photos

## Objetivo

Esta carpeta contiene el banco oficial de fotografías de Aberturas VC.

Las imágenes aquí almacenadas representan la principal fuente visual para campañas, redes sociales, sitio web, presentaciones comerciales y material institucional.

---

## Prioridad de uso

Siempre utilizar las fotografías en el siguiente orden:

1. Obras reales de Aberturas VC.
2. Instalaciones realizadas por la empresa.
3. Productos reales.
4. Equipo de trabajo.
5. Fotografías de stock (únicamente cuando no exista material propio).

---

## Organización recomendada

La carpeta puede organizarse de la siguiente manera:

- Obras
- Casas
- Departamentos
- Interiores
- Exteriores
- PVC
- Aluminio
- Detalles
- Equipo
- Institucional

---

## Reglas

- Priorizar siempre fotografías reales.
- Evitar imágenes oscuras.
- Evitar fotografías con exceso de edición.
- Evitar HDR exagerado.
- Mantener una estética moderna, limpia y luminosa.
- Mostrar arquitectura contemporánea.
- Dar protagonismo a las aberturas sin perder el contexto arquitectónico.

---

## Relación con el Design System

Las reglas visuales para el uso de fotografías se encuentran documentadas en:

- design/PHOTOGRAPHY.md

## Objetivo final

Construir un banco de imágenes consistente que permita crear piezas visuales alineadas con la identidad de Aberturas VC y facilite el trabajo de diseñadores e inteligencias artificiales.

---

# Relación entre campañas y fotografías

Antes de seleccionar una fotografía, la IA debe identificar el objetivo de la campaña y elegir la carpeta correspondiente.

| Tipo de campaña | Carpeta recomendada |
|-----------------|---------------------|
| Beneficios del PVC | pvc |
| Beneficios del aluminio | aluminio |
| Obras terminadas | obras |
| Instalaciones | instalaciones |
| Campañas institucionales | equipo |
| Fabricación | fabrica |
| Diseño de interiores | interiores |
| Arquitectura y fachadas | exteriores |

Si varias carpetas pueden representar correctamente el objetivo de la campaña, priorizar siempre la fotografía de mayor calidad y que mejor represente el beneficio principal.

---

# Reglas para IA

Antes de generar una imagen nueva, seguir este proceso:

1. Analizar el objetivo de la campaña.
2. Identificar el público principal utilizando AUDIENCE.md.
3. Identificar el beneficio principal utilizando CAMPAIGN_STRATEGY.md.
4. Consultar ART_DIRECTION.md para definir el estilo visual.
5. Buscar primero una fotografía dentro de esta biblioteca.
6. Seleccionar la carpeta que mejor represente el beneficio principal.
7. Priorizar siempre fotografías reales de Aberturas VC.
8. Solo generar una imagen nueva cuando no exista un recurso adecuado.

Nunca ignorar esta biblioteca si existe una fotografía que represente correctamente el objetivo de la campaña.
