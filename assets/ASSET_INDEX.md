# ASSET_INDEX

# Objetivo

Este documento es el índice maestro de todos los recursos visuales oficiales de Aberturas VC.

Antes de comenzar cualquier diseño, la IA debe consultar este documento para identificar qué biblioteca contiene los recursos adecuados para la campaña.

Nunca generar una imagen nueva sin revisar primero las bibliotecas oficiales.

# Flujo obligatorio

Antes de comenzar cualquier diseño:

1. Identificar el objetivo de la campaña.
2. Identificar el público principal.
3. Identificar el beneficio principal.
4. Consultar ASSET_INDEX.md.
5. Seleccionar la biblioteca correspondiente.
6. Abrir el INDEX.md de esa biblioteca.
7. Elegir el recurso más adecuado.
8. Solo si no existe un recurso compatible, generar uno nuevo.

---

# Reglas para IA

Nunca ignorar la biblioteca oficial.

Nunca solicitar una fotografía nueva si existe una fotografía oficial adecuada.

Priorizar siempre los recursos oficiales de Aberturas VC.

La generación de recursos nuevos debe ser la última alternativa.
