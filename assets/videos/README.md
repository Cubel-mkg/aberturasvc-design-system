# Videos

## Objetivo

Esta carpeta contiene todos los recursos audiovisuales oficiales de Aberturas VC.

Los videos aquí almacenados sirven como material base para redes sociales, campañas publicitarias, sitio web y comunicación institucional.

---

## Contenido esperado

Esta carpeta puede incluir:

- Reels
- Videos institucionales
- Instalaciones
- Obras finalizadas
- Testimonios
- Timelapses
- Videos de productos
- Material para publicidad

---

## Organización recomendada

Se recomienda organizar el contenido por categorías:

- Reels
- Institucional
- Obras
- Instalaciones
- Productos
- Testimonios
- Detrás de escena

---

## Reglas

- Priorizar siempre material propio.
- Mantener buena iluminación.
- Mostrar instalaciones reales.
- Evitar exceso de efectos.
- Mantener un estilo profesional y moderno.
- Utilizar tomas estables y de buena calidad.

---

## Relación con el Design System

Las reglas para la producción audiovisual se encuentran documentadas en:

- patterns/instagram-reel.md
- design/VISUAL_DNA.md
- brand/VOICE.md

Esta carpeta contiene únicamente los archivos de video oficiales.

---

## Objetivo final

Centralizar todos los recursos audiovisuales oficiales de Aberturas VC para facilitar la producción de contenido consistente y alineado con la identidad de la marca.
