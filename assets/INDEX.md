# Assets — Aberturas VC

## Objetivo

Esta carpeta contiene todos los recursos visuales oficiales de Aberturas VC.

Antes de solicitar al usuario un archivo, una fotografía, un logo, una tipografía o cualquier otro recurso visual, Claude debe consultar esta carpeta y utilizar los assets disponibles.

---

# Estructura

## examples/

Contiene ejemplos visuales oficiales de publicaciones de Instagram.

Utilizar estos ejemplos para comprender:

- Composición.
- Jerarquía.
- Uso de fotografía.
- Tipografía.
- Color.
- Espaciado.
- Tratamiento del logo.
- Lenguaje visual general.

Los ejemplos son referencias y no deben copiarse literalmente.

---

## fonts/

Contiene las tipografías oficiales disponibles para la marca.

Consultar esta carpeta antes de utilizar una tipografía.

No sustituir una tipografía oficial por otra si el recurso está disponible.

---

## icons/

Contiene iconos oficiales disponibles para las piezas.

Utilizar únicamente cuando el patrón o la estrategia indiquen que un icono aporta una función clara.

No utilizar iconos como decoración.

---

## logos/

Contiene las versiones oficiales del logotipo de Aberturas VC.

El logo debe utilizarse siempre desde esta carpeta.

Nunca recrear el logotipo manualmente.

Nunca sustituirlo por texto cuando exista un archivo oficial disponible.

---

## photos/

Contiene el banco oficial de fotografías de Aberturas VC.

Las fotografías deben seleccionarse desde este directorio antes de considerar cualquier fotografía externa o solicitar una fotografía al usuario.

Consultar los INDEX.md de las categorías correspondientes para determinar qué fotografía se adapta mejor a cada campaña.

Prioridad:

1. Obras reales de Aberturas VC.
2. Instalaciones reales.
3. Productos reales.
4. Equipo de trabajo.
5. Stock únicamente si no existe material propio adecuado.

---

## videos/

Contiene material audiovisual oficial de Aberturas VC.

Utilizar para:

- Reels.
- Stories.
- Contenido audiovisual.
- Otros formatos de video.

---

# Regla de selección de assets

Antes de comenzar una pieza:

1. Identificar el objetivo.
2. Identificar el público.
3. Identificar el beneficio.
4. Determinar qué tipo de fotografía o recurso visual requiere la pieza.
5. Consultar `assets/`.
6. Seleccionar el asset oficial más adecuado.
7. Utilizar ese asset en la pieza.

---

# Regla crítica

No pedir al usuario que suba nuevamente un asset que ya existe dentro de `assets/`.

Si existe una fotografía adecuada en `assets/photos/`, utilizarla.

Si existe un logotipo adecuado en `assets/logos/`, utilizarlo.

Si existe una tipografía adecuada en `assets/fonts/`, utilizarla.

Si existe un ejemplo visual relevante en `assets/examples/`, utilizarlo como referencia.

---

# Cuando no exista un asset adecuado

Solo solicitar material adicional al usuario cuando:

- No exista una fotografía adecuada.
- No exista una versión correcta del logotipo.
- No exista la tipografía requerida.
- El brief requiera un recurso que todavía no esté disponible.

En ese caso, explicar exactamente qué recurso falta.

---

# Prioridad

Los assets oficiales de Aberturas VC tienen prioridad sobre:

- Stock genérico.
- Imágenes generadas.
- Recursos externos.
- Placeholders.
- Elementos recreados manualmente.

La documentación del Design System determina cómo deben utilizarse los assets.
