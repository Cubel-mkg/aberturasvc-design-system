# NAMING_CONVENTIONS

# Objetivo

Definir una convención única para nombrar todos los recursos visuales del Creative OS.

Los nombres de archivos deben ser descriptivos, consistentes y fáciles de interpretar tanto por personas como por inteligencias artificiales.

Nunca utilizar nombres automáticos generados por cámaras o teléfonos (IMG_1234.jpg, DSC0001.jpg, etc.).

---

# Formato

Todos los archivos deben seguir esta estructura:

categoria-tipo-beneficio-numero.ext

Ejemplo:

pvc-living-confort-001.jpg

---

# Categorías

- pvc
- aluminio
- obra
- instalacion
- interior
- exterior
- fabrica
- equipo
- logo
- icon

---

# Tipo

Describe el contenido principal.

Ejemplos:

- living
- cocina
- dormitorio
- fachada
- ventana
- puerta
- balcon
- oficina

---

# Beneficio

Describe el mensaje que comunica.

Ejemplos:

- confort
- thermal
- acoustic
- design
- security
- architecture
- quality
- production
- trust

---

# Número

Tres dígitos.

Ejemplos:

001

002

003

---

---

# Reglas

Nunca utilizar espacios.

Nunca utilizar acentos.

Nunca utilizar nombres genéricos.

Los nombres deben permitir identificar el recurso sin necesidad de abrir el archivo.

---

# Reglas para IA

Antes de seleccionar un recurso:

Leer su nombre.

Verificar que coincida con el beneficio principal de la campaña.

Priorizar siempre el recurso cuyo nombre describa mejor el objetivo buscado.
