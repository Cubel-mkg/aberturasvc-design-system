# Objetivo

Invitar al usuario a solicitar una cotización utilizando una obra real como respaldo visual.

El foco no está en vender agresivamente.

El objetivo es facilitar el primer contacto.

---

# Público

- Familias construyendo una vivienda.
- Arquitectos.
- Constructoras.
- Desarrolladores.

---

# Componentes utilizados

- TITLE_PRIMARY
- CTA_PRIMARY
- LOGO_PLACEMENT_STANDARD

---

# Composición

La fotografía ocupa prácticamente toda la pieza.

El texto se ubica sobre una zona limpia del cielo para garantizar una excelente legibilidad.

Existe un único punto focal.

La vista hacia el exterior transmite amplitud y calidad.

---

# Fotografía

Fotografía real tomada desde el interior de una obra.

La abertura enmarca el paisaje.

El producto forma parte de la arquitectura.

No parece una fotografía publicitaria.
