# INSTAGRAM_POST.md
# INSTAGRAM POST LAYOUT

## Objetivo

Este documento define la estructura oficial para las publicaciones de Instagram de Aberturas VC.

Todo post debe seguir uno de estos layouts.

Nunca improvisar una composición completamente nueva.

---

# Formato

Resolución

1080 x 1350 px

Relación

4:5

Plataforma

Instagram Feed

---

# Objetivo del diseño

Cada publicación debe comunicar UNA sola idea.

No intentar comunicar demasiados mensajes.

Una publicación = Un mensaje.

---

# Jerarquía visual

El orden de lectura debe ser:

1. Fotografía

↓

2. Título

↓

3. Beneficio

↓

4. CTA

↓

5. Logo

---

# Distribución visual

Fotografía

70% - 80%

# Logo

Siempre presente.

Nunca protagonista.

Ubicación recomendada

Esquina inferior derecha.

Puede utilizarse también la esquina superior derecha.

---

# Márgenes

Nunca colocar texto pegado a los bordes.

Mantener márgenes amplios.

Priorizar aire visual.

---

# Texto

Título

Máximo 3 líneas.

Beneficios

Máximo 3 beneficios.

CTA

Una sola llamada a la acción.

CTA principal

Solicitar presupuesto.

---

# Fotografía

Siempre utilizar fotografías reales.

Priorizar:

- Obras reales
- Viviendas modernas
- Arquitectura contemporánea
- Luz natural

Evitar:

- Renderizados
- Fotografías oscuras
- Fotografías pixeladas
- Stock genérico

---

# Color

El azul institucional organiza la composición.

Nunca utilizar demasiados bloques azules.

El color acompaña.

No domina.

---

# Checklist

Antes de exportar verificar:

✓ El mensaje se entiende en menos de 3 segundos.

✓ La fotografía es protagonista.

✓ El título tiene buena jerarquía.

✓ El logo está correctamente ubicado.

✓ Hay suficiente espacio en blanco.

✓ El CTA es claro.

✓ La composición respeta la identidad de Aberturas VC.
