# DECISION_TREE

# Objetivo

Este documento define el proceso de decisión obligatorio que debe seguir la IA antes de desarrollar cualquier pieza de comunicación para Aberturas VC.

No debe comenzar ningún diseño sin recorrer completamente este flujo.

Cada decisión debe justificarse utilizando la documentación del proyecto.

Nunca improvisar.

---

# Flujo de decisión

Toda campaña debe seguir este orden.

Objetivo de la campaña

↓

Público principal

↓

Beneficio principal

↓

Patrón

↓

Fotografía

↓

Componentes

↓

Copy

↓

Control de calidad

Nunca alterar este orden.

---

# PASO 1

## Identificar el tipo de contenido

Determinar qué pieza solicita el usuario.

IF Instagram Feed

→ Continuar

IF Carrusel

→ Utilizar PATTERN_INSTAGRAM_CAROUSEL

IF Story

→ Utilizar PATTERN_INSTAGRAM_STORY

IF Reel

→ Utilizar PATTERN_INSTAGRAM_REEL

---

# PASO 2

## Definir el objetivo de la campaña

Preguntarse:

¿Qué queremos lograr?

Ejemplos:

- Presentar la empresa.
- Mostrar una obra.
- Mostrar un beneficio.
- Presentar un producto.
- Generar consultas.
- Mostrar una instalación.
- Reforzar la confianza.
- Posicionar la marca.

El objetivo condiciona todas las decisiones posteriores.

---

# PASO 3

## Seleccionar el público principal

Consultar AUDIENCE.md.

Responder:

¿Quién obtiene mayor valor con esta campaña?

Seleccionar:

- Arquitectos
- Constructoras
- Clientes particulares

Si corresponde, identificar también públicos compatibles.

Nunca seleccionar un público únicamente porque aparezca mencionado en el prompt.

Siempre priorizar el objetivo estratégico.

---

# PASO 4

## Definir el beneficio principal

Preguntarse:

¿Qué gana el cliente?

El beneficio siempre debe comunicarse antes que la característica técnica.

Nunca intentar comunicar varios beneficios importantes en la misma pieza.

Elegir solamente uno.

---

# PASO 5

## Seleccionar el patrón

Elegir el patrón según el objetivo.

IF Mostrar una obra

→ PATTERN_INSTAGRAM_PROJECT

IF Mostrar beneficios

→ PATTERN_INSTAGRAM_BENEFITS

IF Presentar un producto

→ PATTERN_INSTAGRAM_PRODUCT

IF Hablar de la empresa

→ PATTERN_INSTAGRAM_CORPORATE

IF Mostrar una instalación

→ PATTERN_INSTAGRAM_INSTALLATION

IF Presentar un proyecto destacado

→ PATTERN_INSTAGRAM_HERO

El patrón debe responder al objetivo de la campaña, nunca únicamente al formato solicitado.

---

# PASO 6

## Seleccionar la fotografía

Consultar PHOTOGRAPHY.md.

Orden de prioridad:

1. Obras reales de Aberturas VC.
2. Fotografías propias.
3. Material producido por el equipo.
4. Banco de imágenes relacionado con arquitectura.

Nunca utilizar imágenes genéricas cuando exista material propio.

La fotografía siempre es el principal elemento visual de la pieza.

---

# PASO 7

## Seleccionar componentes

Consultar COMPONENTS.

Componentes obligatorios:

- TITLE_PRIMARY
- LOGO_PLACEMENT_STANDARD

Componentes opcionales:

- CTA_PRIMARY
- CARD_STANDARD
- BADGE_PRIMARY
- ICON_STANDARD

Nunca utilizar un componente que no aporte valor.

Cada componente debe cumplir una función específica.

---

# PASO 8

## Redactar el copy

Consultar:

- VOICE.md
- POSITIONING.md

El mensaje debe:

- comunicar un único beneficio.
- utilizar un tono profesional.
- hablar primero del cliente.
- evitar tecnicismos innecesarios.
- mantener coherencia con la marca.

El CTA debe seleccionarse según CTA.md.

---

# PASO 9

## Control de calidad

Antes de finalizar verificar:

□ El objetivo está claramente definido.

□ El público principal es correcto.

□ El beneficio es único.

□ El patrón es el adecuado.

□ La fotografía respeta PHOTOGRAPHY.md.

□ Los componentes son los necesarios.

□ El copy respeta VOICE.md.

□ La composición mantiene VISUAL_DNA.md.

□ El logo funciona como firma.

□ La pieza parece una publicación real de Aberturas VC.

---

# Resolución de conflictos

Si dos documentos presentan información diferente:

1. AI_RULES.md
2. CLAUDE.md
3. BRAND.md
4. AUDIENCE.md
5. POSITIONING.md
6. VISUAL_DNA.md
7. COMPOSITION.md
8. COMPONENTS
9. PATTERNS

Siempre prevalece el documento de mayor prioridad.

Nunca combinar reglas contradictorias.

---

# Regla final

No improvisar.

Si una decisión ya está documentada, seguir la documentación.

Si falta información, indicarlo explícitamente antes de continuar.

La consistencia siempre tiene prioridad sobre la creatividad.
