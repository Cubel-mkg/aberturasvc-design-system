# PROMPT_ENGINE

# Objetivo

Definir cómo la IA debe construir internamente el prompt antes de generar cualquier pieza gráfica.

La calidad del resultado depende directamente de la calidad del prompt.

El prompt nunca debe comenzar describiendo únicamente la imagen.

Primero debe construir el contexto estratégico.

---

# Principio

La IA nunca debe generar una imagen directamente.

Primero debe comprender:

- Qué debe comunicar.
- A quién.
- Cómo debe sentirse.
- Cómo debe verse.

Solo después podrá construir el prompt visual.

---

# Orden obligatorio

Todo prompt debe construirse siguiendo este orden.

1. Objetivo comercial.

2. Público principal.

3. Beneficio principal.

4. Emoción.

5. Concepto creativo.

6. Dirección de arte.

7. Composición.

8. Fotografía.

9. Componentes.

10. Copy.

11. CTA.

12. Restricciones.

Nunca alterar este orden.

---

# Objetivo comercial

Explicar claramente qué debe lograr la pieza.

Ejemplos:

- Generar consultas.
- Fortalecer la marca.
- Mostrar una obra.
- Presentar un producto.
- Comunicar un beneficio.

---

# Público

Definir:

- Público principal.
- Públicos compatibles.

La imagen debe hablar principalmente al público principal.

---

# Beneficio

Seleccionar únicamente un beneficio.

Nunca intentar comunicar varios beneficios principales.

---

# Emoción

Consultar EMOTIONS.md.

Definir una única emoción dominante.

Toda la pieza debe transmitir esa emoción.

---

# Concepto creativo

Consultar CREATIVE_CONCEPTS.md.

Resumir la idea central.

Toda decisión visual debe reforzar ese concepto.

---

# Dirección de arte

Consultar ART_DIRECTION.md.

Definir:

- Ambiente.
- Estilo.
- Iluminación.
- Encuadre.
- Sensación.

---

# Layout

Consultar:

LAYOUT_RULES.md

Definir:

- Punto focal.
- Jerarquía.
- Distribución.
- Espacio negativo.

---

# Fotografía

Consultar:

PHOTOGRAPHY.md

Prioridad:

1. Obras reales.

2. Fotografías propias.

3. Banco de imágenes (solo cuando no exista material propio).

Nunca utilizar imágenes artificiales si existe material real.

---

# Componentes

Consultar:

PATTERNS

COMPONENTS

Seleccionar únicamente los componentes necesarios.

Nunca agregar elementos decorativos.

---

# Restricciones

El prompt debe indicar explícitamente:

- Mantener identidad visual.
- No agregar colores fuera de la paleta.
- No utilizar tipografías ajenas.
- No saturar la composición.
- Mantener mucho espacio negativo.
- Mantener fotografía protagonista.
- Mantener un único mensaje principal.

---

# Resultado esperado

El prompt final debe ser suficientemente preciso para que cualquier IA de generación visual produzca una pieza coherente con la identidad de Aberturas VC.

Debe evitar interpretaciones ambiguas.

Debe describir tanto la intención estratégica como la ejecución visual.

---

# Reglas para IA

Nunca escribir un prompt únicamente describiendo la imagen.

El prompt debe explicar primero el objetivo de comunicación.

Toda descripción visual debe responder al beneficio principal.

Si alguna decisión estratégica no está definida, detener el proceso antes de generar el prompt.
