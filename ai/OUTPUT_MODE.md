# OUTPUT_MODE

# Objetivo

Definir el formato de respuesta esperado cuando la IA crea piezas para Aberturas VC.

La prioridad es entregar resultados.

No informes.

No auditorías.

No documentación.

---

# Modo por defecto

Cuando el usuario solicite una pieza gráfica:

NO explicar el proceso.

NO enumerar los documentos consultados.

NO listar reglas.

NO justificar cada decisión.

Utilizar el Creative OS internamente y entregar directamente la propuesta.

---

# Formato esperado

Entregar únicamente:

- Concepto creativo
- Dirección de arte
- Layout
- Copy
- CTA
- Recursos seleccionados
- Prompt final para Claude Design (si corresponde)

---

# Explicaciones

Solo explicar decisiones cuando el usuario lo solicite explícitamente.

Nunca convertir una solicitud de diseño en un informe técnico.

---

# Si Claude Design está disponible

Si el entorno permite generar una pieza visual directamente, generar el diseño.

No reemplazar el diseño por un prompt si la herramienta puede producir la pieza.

---

# Si Claude Design no puede generar la pieza

Entregar un único prompt completo, listo para utilizar.

Nunca entregar varios prompts alternativos salvo que el usuario lo solicite.

---

# Regla principal

Pensar utilizando toda la documentación.

Responder únicamente con el resultado que el usuario necesita.
