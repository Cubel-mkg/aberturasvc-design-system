# Claude Project Setup

## Objetivo

Garantizar que Claude utilice siempre la versión correcta del Design System.

---

## Antes de subir archivos

1. Guardar todos los cambios en VS Code.

File → Save All

No deben existir archivos "Unsaved".

---

## Carga del proyecto

Crear un nuevo Project en Claude.

Subir los archivos desde la computadora.

No asumir que una carga masiva reemplaza automáticamente archivos existentes.

---

## Verificación

Después de cargar el proyecto solicitar:

- Mostrar CLAUDE.md
- Mostrar BRAND.md
- Mostrar AUDIENCE.md

Verificar que coincidan exactamente con la versión local.

---

## Actualizaciones

Cuando un archivo cambie:

1. Guardarlo.
2. Actualizar GitHub.
3. Reemplazar únicamente ese archivo dentro del proyecto de Claude.
4. Verificar el contenido.

---

## Objetivo

Claude debe trabajar siempre sobre la versión más reciente del Design System.
