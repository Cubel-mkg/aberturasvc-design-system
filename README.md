# Aberturas VC Design System

Sistema oficial de identidad visual, componentes, patrones de diseño y flujo de trabajo para inteligencia artificial de **Aberturas VC**.

Este repositorio fue creado para garantizar que cualquier diseño generado por IA mantenga la identidad visual, el tono de comunicación y los estándares de calidad de la empresa.

---

# Objetivo

El objetivo de este proyecto es permitir que herramientas como Claude generen piezas gráficas consistentes sin depender exclusivamente del criterio humano.

La IA debe comportarse como un Director Creativo de Aberturas VC, respetando la identidad de marca, los principios de diseño y el sistema visual definido en este repositorio.

# Principios

Todo diseño debe ser:

- Profesional.
- Minimalista.
- Elegante.
- Arquitectónico.
- Claro.
- Consistente.

Evitar:

- Diseños recargados.
- Clickbait.
- Promociones agresivas.
- Recursos innecesarios.

---

# Cómo utilizar este repositorio

Antes de generar cualquier diseño:

1. Leer `AI_RULES.md`.
2. Leer `AI_START_HERE.md`.
3. Seguir `DESIGN_WORKFLOW.md`.
4. Elegir el Pattern adecuado.
5. Aplicar los componentes.
6. Ejecutar `QUALITY_CHECKLIST.md`.
7. Realizar `SELF_REVIEW.md`.
