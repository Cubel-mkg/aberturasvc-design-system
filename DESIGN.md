# Aberturas VC Design System

## Objetivo

Este documento resume la filosofía del Design System de Aberturas VC y explica cómo utilizar el repositorio.

No reemplaza la documentación específica.

Actúa como punto de entrada para diseñadores, desarrolladores y herramientas de IA.

---

# Filosofía

El diseño de Aberturas VC debe transmitir:

- Calidad.
- Profesionalismo.
- Confianza.
- Arquitectura moderna.
- Confort.
- Simplicidad.

El objetivo no es decorar.

El objetivo es comunicar valor.

---

# Principios fundamentales

Todo diseño debe cumplir estos principios:

1. La fotografía es protagonista.
2. Un único mensaje principal.
3. Mucho espacio en blanco.
4. Jerarquía visual clara.
5. Tipografía consistente.
6. Colores institucionales.
7. Logo utilizado como firma.

# Flujo recomendado

Antes de comenzar un diseño:

1. Definir el objetivo.
2. Identificar el público.
3. Seleccionar el Pattern.
4. Aplicar los Components.
5. Utilizar el Template correspondiente.
6. Validar con QUALITY_CHECKLIST.
7. Ejecutar SELF_REVIEW.

---

# Objetivo final

Todo diseño debe ser reconocible como parte de Aberturas VC incluso si el logotipo estuviera oculto.

La consistencia es más importante que la originalidad.

La identidad siempre tiene prioridad sobre la tendencia.
